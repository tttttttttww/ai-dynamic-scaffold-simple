# AI 学习助手（多班名单版）

## 主要功能

- 教师后台上传学生名单，支持 `.xlsx` / `.xls` / `.csv`。
- 名单字段：`班级`、`学生编号`、`姓名`。
- 学生登录时选择班级，并输入编号和姓名；三项必须与当前名单一致。
- 学生人数不再限制为 S01–S30，可有多个班、任意合理编号。
- 学生可上传图片并与 Coze 智能体进行连续多轮对话。
- 教师后台可按班级筛选学生，并查看“已进入 / 未进入”。
- 教师可查看完整聊天和学生上传图片，并导出 CSV / JSON。
- 重新上传名单会替换“当前可登录名单”，不会删除已产生的聊天和图片数据。

## EdgeOne Makers 构建设置

- 框架预设：`Other`
- 根目录：`./`
- 输出目录：`public`
- 构建命令：`npm run build`
- 安装命令：`npm install`

构建时会自动把静态页面复制到 `public/`，同时把 Excel 解析组件复制到 `public/vendor/`。

## 环境变量

```text
COZE_ACCESS_TOKEN=你的扣子访问令牌
COZE_BOT_ID=你的智能体 Bot ID
ADMIN_PASSWORD=教师后台密码
DATA_STORE_NAME=ai-dynamic-scaffold-data
EXPERIMENT_RUN_ID=2026-fall
```

前三项必填。后两项可保持默认，也可以按学期/实验批次修改。

## 第一次使用

1. 部署成功后打开首页。
2. 点击首页底部“管理员进入”，输入后台密码。
3. 在后台点击“下载名单模板”。
4. 按模板填写三个字段：班级、学生编号、姓名。
5. 点击“上传学生名单”，选择 Excel 或 CSV 文件。
6. 上传成功后，学生首页会自动显示当前名单中的班级。
7. 学生选择班级，输入编号和姓名后进入。

## 名单更新规则

- 同一班级中，学生编号必须唯一。
- 不同班级可以使用相同编号，例如七年级1班和七年级2班都可以有 S01。
- 修改姓名后重新上传，只要“班级 + 学生编号”不变，已有学习记录仍会对应到该学生。
- 如果把学生改到另一个班级或修改学生编号，系统会把它视为新的学生身份；旧聊天不会被删除，会保留为历史数据。

## 数据安全

- `COZE_ACCESS_TOKEN` 只存放在 EdgeOne 环境变量中，不会发到浏览器。
- 教师后台需要管理员密码。
- 学生登录必须匹配后台当前名单。


## 固定测试账号

无需上传名单即可使用：

- 班级：`测试`
- 学生编号：`S00`
- 姓名：`测试`

该账号会显示在教师后台，并标记为“测试”。默认“导出正式 CSV / JSON”不会包含 S00 数据。
正式学生仍必须来自教师后台上传的名单。


## 学生端图片优先流程

学生进入后可直接选择作品图片，不需要先输入文字。选择图片后点击“发送给 AI”，图片会直接传给已配置的 Coze 智能体，随后学生可继续用文字进行多轮对话。

## v10：姓名登录 + 三任务数据隔离

- 学生端只输入姓名，不再输入班级和编号。
- 固定测试账号：姓名输入 `测试`（也兼容输入 `S00`）。
- 教师后台固定提供 `任务1 / 任务2 / 任务3` 三个任务，并由老师控制当前任务。
- 同一学生在同一任务中再次进入，会恢复该任务已有对话并继续同一个 Coze conversation_id。
- 老师切换当前任务后，学生端会自动进入新任务；三个任务的数据和 Coze 会话彼此独立。
- 教师后台点击学生后，可分别查看三个任务的完整对话与上传图片；后台约每 5 秒自动刷新一次。
- 名单模板现在只需要一列：`姓名`。若名单中存在重名，系统会拒绝导入，因为仅靠姓名无法区分两个学生。


## v12 修复
- 历史版本产生的多个 S00/测试账号在后台自动合并为唯一测试账号，历史测试对话仍可查看。
- 封面管理员密码验证成功后直接进入后台，不再重复输入；后台登录最长保持 12 小时，主动退出后失效。


## v13：无需名单，姓名直接进入

- 不需要上传学生名单。
- 学生只输入姓名即可进入；第一次进入时系统自动建立该学生记录。
- 同一姓名再次进入，会继续老师当前任务下原来的对话。
- 老师切换任务后，学生进入该任务的新对话；每个任务第一次提交必须先上传作品图片。
- 姓名“测试”（兼容 S00）为教师测试账号，默认不进入正式导出。
- 若班级中存在完全同名的两位学生，需要提前给其中一位加固定识别标记，否则相同姓名会被视为同一学生。
